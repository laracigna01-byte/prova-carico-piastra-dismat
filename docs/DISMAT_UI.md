# DISMAT UI 0.2 — Display Control
Riferimento estetico: [RemotePanel.ps1](https://github.com/laracigna01-byte/dismat-display-control/blob/489e801491b6bb0b184d51016da582d260c617e4/app/RemotePanel.ps1), blocco palette ufficiale grafite/ambra/rosso.
display-core.css e luminous-switch.css sono uguali nelle quattro app React; il core CSS è utilizzabile anche da Angular. Il componente sole/luna conserva il design approvato e lo stato tema preesistente.
Il tema chiaro è una derivazione avorio calda (Display Control originale è scuro). Gli adattatori rispettano le differenze funzionali; non sono stati cambiati motori, generatori PDF/Excel, autenticazione, archivi o workflow di prova. Non è ancora una libreria distribuita: i file sono copie versionate identiche.
Collaudo necessario: entrambe le modalità, smartphone, dati/archivi, PDF ed Excel, contrasto e visibilità comandi. La revisione è limitata all'area operativa; login e aree ufficio ancora da uniformare. Nessuna modifica a Nexus Core o Display Control. Le app restano destinate al catalogo Nexus; autenticazione unica non ancora implementata.
